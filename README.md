One line, at most 200 characters, roasting my own fridge — for make.fun's "One Line, One Laugh: Roast Your Fridge" bounty. The program writes the line to `/output/entry.txt`, where the house judge reads it.

The line: *"My fridge's filter light has glowed since 2023; it's no longer a warning, it's the longest relationship in my kitchen."*

Why this line: it roasts a specific, recognisable detail — the water-filter warning light every modern fridge owner ignores for years — the twist lands in the final words, it reads cleanly aloud in one breath, and it dodges the worn-out cracks about milk, ice, and opening the door hoping food appears. 118 characters.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, one line, 1–200 characters). Stdlib only, deterministic, no network.
